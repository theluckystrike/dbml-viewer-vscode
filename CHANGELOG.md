# Changelog

## 0.1.0

- First release: a live ER diagram for DBML, SQL DDL (PostgreSQL, MySQL, SQL Server, SQLite) and Prisma schemas, with crow's foot relations, automatic layout, drag to arrange, search, zoom, click to jump to the line, and Copy SVG.
- DBML language support: syntax colors, problems with line and column, outline and go to definition.
- Zovo Pro tools with 3 free tries each: export SQL or DBML, export the diagram as PNG, SVG, PDF or a Markdown data dictionary, and a schema diff with migration SQL.
- The walkthrough ends with a step that links free Zovo extensions for SQL databases and Graphviz graphs. A link opens the extension page; nothing installs on its own.
