# Arrange, search and copy

- Drag a table to move it. The layout is kept for each file; Reset layout lays everything out again.
- Scroll to pan, Ctrl or Cmd + scroll to zoom, Fit to see the whole schema.
- Find a table highlights the matches; Enter moves to the next one.
- Hover a relation line to see both columns and the relation type.
- Click a table or a column to jump to its line in the editor.
- Copy SVG puts the diagram on the clipboard as an SVG image.
